# Music 机器人 · 使用、管理与上线

设计见 [music-bot-design](../superpowers/specs/2026-11-17-music-bot-design.md)，实施计划见 [music-bot plan](../superpowers/plans/2026-11-17-music-bot.md)。**代理未部署，也未连接过真实 Discord、网易云或 SOCKS 代理**；本文第 5 节列出必须由机主在真实环境验收的项目。

## 1. 成员怎么用

1. 进入自己的语音房，点房内控制卡上的 **音乐播放器**，或在网页「社区中心 → 语音房间」的房间卡片点同名入口，打开 `/community/music/<房间>`。
2. 点 **邀请 Music 进房**。Music 同一时间只服务一个房间，被占用时显示「正在其他房间使用」。
3. 搜索歌曲或粘贴歌单链接加入队列。播放、暂停、切歌、拖进度、音量、循环模式、队列管理都在这个网页；能查看该房间的成员共用控制。
4. 想播会员曲目：在播放页扫码登录自己的网易云，再点 **用我的账号播放**。登录态加密保存 30 天，期间免扫码；随时可在同一页退出。

网页操作需要登录 Nanako、绑定 Discord 且仍在服务器内，与其他社区网页功能一致。

Music 会在这些情况自动离开：有人点「让 Music 离开」、房内连续 60 秒没有真人、空队列闲置 10 分钟、房间关闭、被移出频道、进程重启。Music 在房内时会被计入房间人数，所以它必须先走，临时空房才会进入回收倒计时。

## 2. 网易云账号

- 账号只存在该成员名下，不会自动带入任何房间；只有成员本人点了「用我的账号播放」（或邀请时勾选）才用于那一次会话。会话结束即解除。
- 带入后，房内成员可以用它播放歌曲，并能看到该账号的网易云昵称与是否会员，看不到其他账号资料。登录前的确认文字已写明这一点。
- 登录态以 `AI_CONFIG_MASTER_KEY` 加密存库，不返回浏览器、不进日志。到期、本人退出、解绑 Discord、离开服务器、网易云判定失效时删除；离服后仍可在网页退出登录。账号主人不再是服务器成员时，正在使用它的会话会改为免登录播放并提示。
- 这是网页端的非官方接入：接口可能变动，账号存在被网易云风控的可能。登录前页面有明示确认，由成员自行决定。

## 3. 管理员

**设置 → 社区管理 → 音乐机器人**：

- **出口代理**：填 `socks5://用户:密码@主机:端口`（也支持 `socks5h://`、`socks4://`）。地址加密保存，页面之后只显示主机与端口，不回显密码。
- **音频也走代理**：默认关闭，只有网易云接口请求走代理；打开后歌曲下载也走代理（代理带宽要够）。
- **测试连接**：经代理向网易云发一次搜索，返回成功或失败。
- 代理已配置但不可用时，网易云请求直接失败并提示，不会悄悄改走直连。

服务器在海外时，不配国内出口代理会有大量歌曲取不到播放地址。

## 4. 上线步骤（机主执行）

1. **新建 Discord 应用**：Developer Portal → New Application（例如命名 Music）→ Bot → 复制 Token。不需要任何特权 Intent。
2. **邀请进服务器**，授予：查看频道、连接、说话、发送消息、嵌入链接。
3. **环境变量**（Coolify，运行时变量）：

   | 变量 | 给谁 | 说明 |
   |---|---|---|
   | `MUSIC_ENABLED=true` | app、bot、music | 总开关；需要 `COMMUNITY_ENABLED=true` |
   | `MUSIC_DISCORD_TOKEN` | 仅 music | 新应用的 Bot Token |
   | `MUSIC_DISCORD_APP_ID` | bot | 新应用的 Application ID（主 Bot 用它给 Music 开临时房权限） |
   | `AI_CONFIG_MASTER_KEY` | app、music | 已有；两边必须相同 |

4. **镜像**：运行层新增 `ffmpeg`，需重新构建并拉取新镜像。
5. **迁移**：`server/migrations/0013_music.sql` 由现有 `migrate` 服务自动应用；先按原流程备份。
6. 升级 app、bot，并启动新的 `music` 服务（无端口、无域名，内存上限 256m）。保持主 Bot 单实例。
7. 在「设置 → 社区管理 → 音乐机器人」按需配置出口代理并测试。

未设置 `MUSIC_DISCORD_TOKEN` 时 `music` 服务空转且健康，播放页显示「Music 机器人离线」。关闭 `MUSIC_ENABLED` 后控制卡上的入口在下一次同步时消失，音乐接口返回 404。

## 5. 必须在真实环境验收的项目

本地只用假的 Discord、假的网易云响应和内嵌 PostgreSQL 验证过逻辑。以下各项没有任何本地证据：

- [ ] Music 能进入公开、锁门、隐藏的临时房；固定房在已有权限下能进，缺权限时页面如实提示。
- [ ] 语音连接成功并出声（Discord 语音现在要求 DAVE 端到端加密，依赖 `@discordjs/voice` 自带的实现；Alpine 镜像里它的原生模块能否加载需确认）。
- [ ] ffmpeg 转码的音质、音量调节与拖进度时的停顿是否可接受。
- [ ] 网易云网页端接口当前是否仍按实现的格式工作：搜索、歌单、取播放地址、扫码登录（含扫码成功后能否取得登录态）。
- [ ] 海外出口直连时的失败提示，以及配置 SOCKS 代理后的效果。
- [ ] 会员账号带入后能播放会员曲目；30 天内免扫码；退出后立即失效。
- [ ] Music 离开后临时空房按原时间回收；主 Bot 的房管、欢迎、身份功能不受影响。
- [ ] `music` 服务重启、数据库短暂不可用后的恢复；滚动发布时两个 `music` 实例重叠，后启动的应保持待命。
- [ ] 经 SOCKS 代理访问 https 目标（本地只用假代理验证了 http）。
- [ ] 每首歌从头播放、暂停后调音量再继续、暂停超过一分钟后继续。

## 6. 已知限制

- 单个 Music 账号，同一时间一个房间。数据按「会话」建模，后续可扩展为多账号。
- 只有网易云一个音源。音源走统一接口，后续可加 Bilibili 等海外可直连的来源。
- 没有 Discord 内的点歌命令、歌词和个人歌单浏览。
- 调节音量或拖进度会从当前位置重新起播，有短暂停顿。
- 搜索、指令、扫码的限速与二维码归属记录在 app 进程内存中，重启后重置。
- music 进程停止上报超过 90 秒，网页会把进行中的会话结束并显示「机器人离线」。
- Music 与主 Bot 的权限操作之间有时间差：邀请后房间若立刻被改名等操作改动，本次开权限可能冲突，重新邀请即可。
- 换绑 Discord（而非解绑）时，旧 Discord 账号名下保存的登录态不会立即删除，最长保留到 30 天到期。
