# C6 · 社区管理员设置保存与表单修复

2026-10-29，基于最新 main `47b309d`（#47）。用户反馈「社区设置格式或范围无效」，要求修复管理员界面。

## 1. 已复现问题与边界

- 新网页会将旧 GET 配置规范化，加入 `fixedCategoryRefs: []`；旧后端严格字段白名单拒绝它，返回同一通用 400。本地已对旧 parser 复现，尚未检查线上部署版本。
- 数字清空会被 `Number('')` 转为0；折叠区原生 required 校验会拦截保存事件，页面无法定位；旧保存状态可能与新草稿并存。
- 日志普通故障不应阻断已获授权的配置编辑；401/403仍必须清除私密状态。
- 不更改任何业务范围、启停规则或数值限制，不丢弃空白话题、非空固定分类等用户草稿；继续一次原子保存全部配置。

## 2. 实施顺序与 TDD

每步先失败测试、实现、通过后提交，格式 `<type>: <中文>（C6）`，无署名。

1. 同一校验源提供结构化字段路径、中文标签、具体约束；HTTP只对已授权管理员的设置输入返回安全字段问题，任何值／ID／密钥不回显。
2. 依据 GET 实际字段识别后端固定房能力；旧后端普通保存保持旧shape，明确阻止非空新功能被静默丢弃；不对400盲目删字段重试。API保留结构化错误。
3. 管理员分组呈现、统一错误摘要／字段关联／展开定位与焦点、数字原始文本、保存／草稿状态区分、可选日志降级；固定管理员独立操作、离开保护和异步权限隔离保留。
4. 本机浏览器检查桌面与390/320px、错误定位／旧后端／保存失败保留修改；更新契约及全量验证后提一个PR并停下。
