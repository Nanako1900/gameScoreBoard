# C4 · 简化临时房与房内控制卡

2026-10-29。机主确认按上一轮分析实施：进入创建入口自动建房并移入；空房按配置时间回收；每房自带文字聊天里一张原地更新的控制卡；网页常用设置收拢；已有房间再次进入入口送回原房。

## 1. 范围与契约

- 成员日常只需进入创建入口；不要求网页登录、查找全局控制台或手动刷新。
- 默认房名沿用「成员名 的房间」；仅管理 Bot 登记的临时房，不接管固定频道。
- 空房计时、重入取消、离线后重新观察、真实删除前复查和建房审计找回继续保留。
- 公共卡显示房名、房主、人数、访问模式与回收规则，提供改名、人数、访问方式、更多；个人输入和授权提示仅本人可见。
- 房内卡内容变化编辑原消息；重启找回、已删除补建，无法证明唯一时暂停补发。面板故障不使已建房间失败或隔离。
- 卡片按钮仅携随机房间引用，点击和执行时重新校验当前授权与版本。
- 网页常用项为房间开关、入口、分类、空房删除分钟、默认人数；高级设置和诊断折叠。旧秒值无损保存。
- 欢迎、自选身份、趣味、计分、案件、语音证据、旧地址和 D1 404 能力边界保持现有契约。
- 无部署、远程迁移、真实 Discord 调用；不新增特权 Intent，不读取聊天正文。

## 2. 顺序与 TDD

每步先写失败测试，再实现，通过后提交；提交格式 `<type>: <中文>（C4）`，无署名。

1. **房内卡渲染与 Discord 适配**：语音文字聊天专用消息适配、持久 marker、自有作者核验、完整分页找回、相同内容不写、未知回执不盲目重发。验证缺权限／多义／分页失败／消息删除／发送后崩溃。
2. **生命周期与交互**：独立面板同步、创建／成员进出／配置与房主变化触发、定期修复、故障隔离；原房回流仅本人且执行时仍在入口；共享卡操作进入当前授权的私密表单和更多功能。验证旧按钮、延迟任务、退出／换绑、断线和只读。
3. **网页简化**：成员引导与本人相关房间、折叠辅助管理；管理员五项常用设置、高级／诊断折叠、异常常显；精确分钟转换与原有草稿／离开保护／迟到请求隔离。
4. **文档与验收**：更新契约与使用说明，浏览器检查桌面及 320/390px，全部八类检查及 server build；PR 按步骤报告前后计数和必要偏离。
