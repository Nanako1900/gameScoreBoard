# Music 机器人与网页播放器 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 房间成员从 Discord 控制卡跳到 Community 播放页，邀请独立的 Music 机器人进房并播放网易云音乐，全部操作在网页完成。

**Architecture:** 新增 `music` 进程（同一镜像）负责语音与转码；app 进程负责 HTTP、网易云搜索与扫码；两者只通过 PostgreSQL（`music_sessions` / `music_commands` + `pg_notify`）交换。主 Bot 只加跳转按钮与临时房权限。

**Tech Stack:** TypeScript、Hono、pg、discord.js 14、`@discordjs/voice` 0.19（含 DAVE）、ffmpeg（Ogg/Opus）、`fetch-socks` + undici、React 18、`qrcode-generator`、vitest。

设计依据：[../specs/2026-11-17-music-bot-design.md](../specs/2026-11-17-music-bot-design.md)。本计划给出文件、接口契约、测试用例与命令；实现代码在执行时按 TDD 写出（先写失败测试，再写最小实现）。

## 通用约定

- 测试命令：`npm run test:unit`、`npm run test:server`、`npm run test:pg`、`npm run test:dom`、`npm run typecheck`。单文件：`npx vitest run --config vitest.server.config.ts server/test/<file>`。
- 不可变数据：reducer 与状态更新一律返回新对象。函数 < 50 行，文件 < 400 行。
- 错误统一抛 `CommunityStoreError(status, code, message)`（`server/src/community/store.ts`），消息为面向成员的中文。
- 浏览器 DTO 只含不透明 ref；不得出现 Discord ID、Cookie、代理密码、网易云原始响应。
- 所有外部依赖（fetch、时钟、语音连接、ffmpeg 进程）经参数注入，测试用假实现。
- 不提交、不部署、不连接真实 Discord / 网易云；提交由机主决定。

## 共享契约（Task 1 落地，其余任务只读）

`shared/music.ts`：

```ts
export type MusicMode = 'order' | 'loop' | 'single' | 'shuffle';
export interface MusicTrack { id: string; title: string; artists: string[]; album: string; durationMs: number; coverUrl: string | null }
export interface MusicQueueItem { key: string; track: MusicTrack; addedBy: string /* member ref */; unplayable?: string }
export interface MusicState {
  current: MusicQueueItem | null; queue: MusicQueueItem[]; history: string[] /* keys, shuffle */;
  mode: MusicMode; volume: number /* 0-100 */; paused: boolean;
  positionMs: number; positionAt: string | null /* ISO; null when paused/stopped */; notice: string | null;
}
export type MusicSessionStatus = 'requested' | 'connecting' | 'active' | 'ended';
export type MusicCommandKind = 'enqueue' | 'remove' | 'move_next' | 'clear' | 'play' | 'pause' | 'skip' | 'seek' | 'volume' | 'mode' | 'leave';
export interface MusicAccountView { nickname: string; vip: boolean; expiresAt: string }
export interface MusicView {
  room: { ref: string; name: string };
  bot: { online: boolean; busyElsewhere: boolean };
  session: { ref: string; status: MusicSessionStatus; version: number; state: MusicState;
    account: { nickname: string; vip: boolean; mine: boolean } | null } | null;
  myAccount: MusicAccountView | null; loginAvailable: boolean; canInvite: boolean; inviteBlocked: string | null;
}
export interface MusicProxyView { configured: boolean; host: string | null; audio: boolean; available: boolean }
export const MUSIC_QUEUE_LIMIT = 200, MUSIC_ACCOUNT_DAYS = 30;
export function defaultMusicState(): MusicState;
export function musicPosition(state: MusicState, nowMs: number): number; // clamp to track duration
```

HTTP（均在现有社区鉴权中间件之后）：

| 方法 路径 | 请求 | 响应 |
|---|---|---|
| GET `/api/community/music/:roomRef` | — | `MusicView` |
| POST `/api/community/music/:roomRef/invite` | `{requestKey, useMyAccount?}` | 202 `MusicView` |
| POST `/api/community/music/:roomRef/commands` | `{requestKey, kind, ...payload}` | 202 `{accepted:true}` |
| POST `/api/community/music/:roomRef/account` | `{requestKey, action:'use'｜'stop'}` | `MusicView` |
| GET `/api/community/music/search?q=` | — | `{tracks: MusicTrack[]}` |
| GET `/api/community/music/playlist?link=` | — | `{name, tracks}` |
| POST `/api/community/music/login/qr` | `{requestKey}` | `{key, url}` |
| GET `/api/community/music/login/qr/:key` | — | `{status:'waiting'｜'scanned'｜'expired'｜'done', account?}` |
| POST `/api/community/music/logout` | `{requestKey}` | `{ok:true}` |
| GET/POST `/api/admin/community/music/proxy` | POST `{requestKey, url｜null, audio}` | `MusicProxyView` |
| POST `/api/admin/community/music/proxy/test` | `{requestKey}` | `{ok, message}` |
